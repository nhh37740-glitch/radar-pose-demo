# 功能和交接关系

一个雷达回放程序，两条执行线程，三个业务 DLL 和一个公共接口 DLL。

界面线程执行“显示图像、画轨迹、响应操作”和“控制播放位置和速度”；文件线程执行“读取位姿和配对图像、导出记录”。控制播放本身不读取磁盘，因此能与界面共用线程。

用户选择数据包或拖动进度 → 控制播放产生带编号的读帧请求 → 排队送到文件线程 → 读取位姿和同时间戳的雷达图、相机图 → 把值副本和请求编号排队交回 → 控制播放检查是否仍是最新请求 → 显示完整同步帧。

打开数据包读取 full/manifest.json 或指定目录的 manifest.json；沿用网页的240帧分页文件、overviewRows及radar/stereo JPEG目录。32字段依次为帧号、雷达时间戳、七种位姿各四值（北、东、下、朝向）、图像主导方法是否接受模型结果、相机时间戳。

默认展示参考位置、雷达主导估计、多帧估计、单帧估计、图像主导估计、仅图像里程计、仅雷达里程计。平面误差为北/东位置差的距离；朝向误差是取最短角度差的绝对值。界面明确写已保存结果回放，不宣称执行在线模型。

文件读取缓存有限，跨分页、首末帧均可直接跳转；停止时先在文件线程执行shutdown，再quit/wait，最后销毁模块。

公开接口和三个radar_create_*工厂都在include/radar/contracts.h。具体业务实现不进入使用模块的调用程序。
